# 🪐 AetherCore Terminal Bestie // Cyberpunk IoT Weather, Aero, Planetary, ... Telemetry Terminal

Настольный гиковый киберпанк-прибор для локального мониторинга среды, атмосферных индексов, космической погоды и авиатрафика в радиусе 100 км. Устройство объединяет «аналоговый» мир комнаты с глобальной сетью таких же терминалов через децентрализованную синхронизацию.

## 🛠 Архитектурный стек
* **Мозг:** ESP32-S3 (DevKitC-1, N16R8 — 16 МБ Flash, 8 МБ Octal PSRAM).
* **Питание:** Стационарное 5В USB (от ПК или PowerBank) через плату расширения с LDO-стабилизаторами.
* **Экраны:** 
  * Основной: 3.5"/4.0" IPS TFT (480x320, SPI/Parallel) с монохромной sci-fi палитрой (угольно-синий, циан, янтарный).
  * Малый: 1.3" OLED (128x64, SH1106) для системного меню и пейджер-чата.
* **Хранение:** MicroSD-карта (кэш векторных карт, TLE-орбит, суточных логов и конфига).
* **Синхронизация:** Google Apps Script (`script.google.com`) — бесплатный шлюз для работы из любой точки мира, включая РФ.
* **Звук:** I2S усилитель (MAX98357A) с процедурным генератором Lo-Fi / Sci-Fi эмбиента.



## 🖥 Режимы работы прибора
1. **Локальная Телеметрия (Indoor Lab):** Микроклимат (температура, влажность, точка росы, барический тренд), лазерный счетчик пыли (PM2.5), сейсмо-акселерометр (ночной/дневной фильтр), спектрометр освещения и уровень шума.
2. **Метео-Радар 100 км (Web API):** Векторная OSM-подложка, погодные слои (ветер, осадки, температура) с переключением кнопкой и подрежимом прогноза на 3 часа вперед (Open-Meteo).
3. **Орбитальный Трекер (Space & Astro):** Расчет реальных пролетов МКС и спутников (SGP4 + TLE), фазы Луны, положение планет и космическая погода NOAA ($Kp$-индекс, солнечный ветер).
4. **Авиарадар (Sky Traffic):** Круговой радар воздушных судов в радиусе 100 км (Ads-b.fi / OpenSky) с карточкой выбранного борта.
5. **Сводная Матрица (Planetary Matrix):** Ключевые риалтайм-показатели и индексы своей или соседней станции из сети.

## 🚀 Быстрый старт (перепишем позднее, когда будет нормальный локальный build)
1. Копируем содержимое папки `config/` на отформатированную в FAT32 MicroSD-карту, заполнив `config.txt` (имя гаджета и список папок сетей).
2. Открываем проект в PlatformIO (VS Code).
3. Ставим зависимости (TFT_eSPI, ArduinoJson, SGP4 и др. из `platformio.ini`).
4. Подключаем ESP32-S3 по USB Type-C и делаем `pio run --target upload`.
