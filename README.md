# 🪐 AetherCore Terminal Bestie // Cyberpunk IoT Weather, Aero, Planetary, ... Telemetry Terminal

Настольный гиковый киберпанк-прибор для локального мониторинга среды, атмосферных индексов, космической погоды и авиатрафика в радиусе 100 км. Устройство объединяет «аналоговый» мир комнаты с глобальной сетью таких же терминалов через децентрализованную синхронизацию.

## 🛠 Архитектурный стек
* **Мозг:** ESP32-S3 (DevKitC-1, N16R8 — 16 МБ Flash, 8 МБ Octal PSRAM).
* **Питание:** Стационарное 5В USB (от ПК или PowerBank) через плату расширения с винтовыми клеммами и буферными конденсаторами.
* **Дисплей:** Единый 3.5"/4.0" IPS TFT (480x320, ST7796) с монохромно-биколорной sci-fi палитрой (угольно-синий, циан, янтарный) и постоянной нижней строкой пейджер-чата.
* **Приборная подсветка:** Тонкие светодиодные нити накала (**LED Filament, 3V**, диаметр 1.5 мм) вдоль рамок панели, управляемые через MOSFET-ключ с плавным ШИМ-диммированием.
* **Сенсорный комплекс:** `ENS160+AHT21` (eCO2, TVOC, AQI, температура, влажность), `BMP280` (давление), `GP2Y1014AU0F` (оптический анализатор пыли), `TCS34725` (спектрометрия света), `INMP441` (уровень шума и аудиоспектр), `MPU6050` (сейсмограф).
* **Управление:** 3 энкодера (`ENC_MODE` — режимы / Назад; `ENC_SUB` — подрежимы / ОК; `ENC_LIGHT` — диммер и Вкл/Выкл подсветки LED Filament), 2 двухпозиционных тумблера (`SW_SRC` — Локалка / Сосед; `SW_NIGHT` — День / Ночь) и аналоговый регулятор громкости.
* **Хранение:** MicroSD-карта (кэш векторных карт, TLE-орбит и конфигурации).
* **Синхронизация:** Google Apps Script (`script.google.com`) — бесплатный шлюз для обмена данными между гаджетами из любой точки мира, включая РФ.
* **Звук:** I2S ЦАП (`PCM5102A`) + усилитель (`PAM8403`) со встроенным аналоговым потенциометром и механическим щелчком выключения для генерации фонового Lo-Fi / Sci-Fi эмбиента.



## 🖥 Режимы работы прибора (переключаются Энкодером 1)
1. **Локальная Телеметрия (Indoor Lab):** Микроклимат, газы ($eCO_2 / TVOC$), оптический замер пыли, сейсмо-акселерометр (ночной/дневной фильтр), RGB-спектр освещения и уровень шума.
2. **Метео-Радар 100 км (Web API):** Векторная OSM-подложка, погодные слои (ветер, осадки, температура) с переключением вторым энкодером и режимом прогноза на 3 часа вперед (Open-Meteo).
3. **Орбитальный Трекер (Space & Astro):** Расчет реальных пролетов МКС и спутников (SGP4 + TLE), фазы Луны, положение планет и космическая погода NOAA ($Kp$-индекс, солнечный ветер).
4. **Авиарадар (Sky Traffic):** Круговой радар воздушных судов в радиусе 100 км (OpenSky / adsb.lol) с захватом цели энкодером и выводом карточки борта.
5. **Сводная Матрица (Planetary Matrix):** Ключевые риалтайм-показатели и индексы своей или соседней станции из сети.
6. **Системный Терминал и Сеть (Menu & Pager):** Выбор соседа из списка сети, отправка сообщения дня (набор текста энкодером), настройка частоты опроса и параметров системы.

## 🚀 Быстрый старт (перепишем позднее, когда будет нормальный локальный build)
1. Копируем содержимое папки `config/` на отформатированную в FAT32 MicroSD-карту, заполнив `config.txt` (имя гаджета и список папок сетей).
2. Открываем проект в PlatformIO (VS Code).
3. Ставим зависимости (TFT_eSPI, ArduinoJson, SGP4 и др. из `platformio.ini`).
4. Подключаем ESP32-S3 по USB Type-C и делаем `pio run --target upload`.
