# 01. Концепция и Архитектура Системы (Cyberpunk Telemetry Station)

## 1. Философия и Визуальный Образ
Проект представляет собой настольный прибор локальной, планетарной и космической телеметрии в эстетике ретро-футуризма, авиационной авионики и научно-космических терминалов (Sci-Fi / Cyberpunk). 

**Ключевая цель:** создать устройство, которое дает тактильный, визуальный и гиковский восторг при ежедневном нахождении на рабочем столе. Гаджет физически исследует среду в комнате через массив реальных сенсоров, сканирует небо и атмосферу вокруг в радиусе $100\text{ км}$ через открытые API и объединяется с такими же устройствами друзей в децентрализованную сеть через инфраструктуру Google.



## 2. Базовые Принципы Проектирования

1. **Стационарное питание $5\text{ V}$ USB без автономности:**
   * Работа от любого порта USB ПК или пауэрбанка через разъем USB Type-C.
   * Постоянное потребление системы ($\sim 250\text{--}380\text{ mA}$) гарантирует, что любой пауэрбанк не уйдет в режим автоотключения.
   * Входной емкостной буфер и раздельная стабилизация гасят импульсные пики тока (до $700\text{ mA}$ при передаче по Wi-Fi и работе лазера), исключая просадки напряжения на стандартном порту USB 2.0 ($500\text{ mA}$).
2. **Отказ от сенсорных экранов в пользу физического контроля:**
   * Никаких тачскринов. Все управление строится на однопозиционных тактильных кнопках с подсветкой (авиационный/приборный стиль), энкодерах и аналоговом потенциометре громкости.
   * Переключение главных режимов и подрежимов вынесено на отдельные физические кнопки на лицевой панели.
3. **Двухэкранная приборная компоновка:**
   * **Основной экран ($4.0\text{"}$ IPS TFT, $480 \times 320$):** отвечает за вывод графических дашбордов, карт погоды, радаров космоса и авиации в строгой 3-цветной научно-технической палитре.
   * **Вспомогательный экран ($1.3\text{"}$ OLED, $128 \times 64$, голубой монохром):** работает как коммуникационный пейджер («Сообщение дня»), индикатор текущего источника данных (`LOCAL` / `NEIGHBOR`) и системное меню с вводом данных энкодером в стиле аппаратур радиоуправления ELRS.
4. **Бессерверная сетевая синхронизация (Google Apps Script + Google Drive):**
   * Устройства объединяются в «сети» через общие папки Google Диска.
   * Обмен данными идет через прослойку `script.google.com`, которая гарантированно доступна из РФ и любой точки мира без VPN и собственных VPS-серверов.
   * Опрос локальных датчиков идет в реальном времени ($1\text{ s}$), а синхронизация с «соседними» устройствами ограничена снизу порогом в $5\text{ s}$ для исключения блокировок по квотам API.
5. **Офлайн-подготовка и кэширование на MicroSD:**
   * При первом запуске пользователь записывает на флешку конфигурационный файл (`config.json`) со своими координатами, сетями и предзагруженными статическими векторными картами местности.
   * При перезагрузке устройство мгновенно поднимает кэш орбит спутников, карт и настроек с MicroSD без лишних запросов в сеть.



## 3. Архитектура Источников Данных

У каждого гаджета три уровня получения информации:
1. **Уровень 1 — Физические модули и сенсоры (Local Hardware):**
   * Химический и лазерный анализ воздуха ($PM_{1.0}$, $PM_{2.5}$, $PM_{10}$, $CO_2$, $VOC$), температура, влажность, барометр, 10-канальный спектрометр света, цифровой микрофон (шум и спектр в $\text{dBA}$), 3-осевой магнитометр ($\mu\text{T}$) и 3-осевой сейсмо-акселерометр.
   * Поддержка **модульной деградации**: если конкретный датчик не распаян в данном экземпляре прибора (или отсутствует у соседа), интерфейс автоматически рисует на его месте техническую заглушку `[ MODULE OFFLINE // N/A ]`.
2. **Уровень 2 — Открытые Web API и Прокси-кэш (External Telemetry):**
   * Погодные сетки и прогнозы (`Open-Meteo API`), сейсмические сводки (`EMSC` / `USGS`), радар самолетов (`OpenSky` / `adsb.lol`), а также орбиты спутников (`CelesTrak`) и космическая погода (`NOAA SWPC`), которые централизованно забираются скриптом Google или админским устройством (находящимся вне РФ) и раздаются всем участникам сети.
3. **Уровень 3 — Телеметрия соседних гаджетов (Mesh Peers):**
   * Переключение источника данных с `LOCAL` на имя любого соседнего устройства из списка сетей полностью перестраивает прибор: режимы локальных датчиков и сводки показывают физическую среду в комнате друга, а режимы карт погоды, космоса и авиации отображают небо и атмосферу над его координатами.



## 4. Распределение Задач по Ядрам ESP32-S3 (FreeRTOS)

Вычислительным ядром системы выступает двухъядерный микроконтроллер **ESP32-S3 (модификация N16R8: $240\text{ MHz}$, $16\text{ MB}$ Flash, $8\text{ MB}$ Octal PSRAM)**. Чтобы сетевые запросы и чтение с SD-карты никогда не вызывали фризов интерфейса или заиканий звука, задачи жестко разделены между ядрами:

```
+-----------------------------------------------------------------------------------+
|                            ESP32-S3 (N16R8: 8MB PSRAM)                            |
+-----------------------------------------+-----------------------------------------+
|          CORE 0 (PRO_CPU)               |             CORE 1 (APP_CPU)            |
|     Сеть, Файловая система и Звук       |      Интерфейс, Датчики и Математика    |
+-----------------------------------------+-----------------------------------------+
| 1. Wi-Fi Stack & HTTPS Client           | 1. Отрисовка 4.0" TFT (буфер в PSRAM)   |
|    - Запросы к script.google.com (>=5s) |    и 1.3" OLED экрана (частота 1-10 Гц) |
|    - Опрос Open-Meteo, ADS-B, USGS      | 2. Опрос кнопок (через MCP23017)        |
| 2. Драйвер MicroSD (чтение карт/кэша)   |    и прерываний энкодера                |
| 3. Процедурный аудио-движок (I2S DMA)   | 3. Опрос датчиков I2C / UART            |
|    - Генерация Lo-Fi/Sci-Fi эмбиента    | 4. Математика SGP4 (орбиты спутников)   |
| 4. FFT-анализ звука с микрофона INMP441 |    и фильтрация сейсмографа (День/Ночь) |
+-----------------------------------------+-----------------------------------------+
```



## 5. Генеративный Аудио-Движок (Data-Driven Ambient)

Звуковой тракт построен на цифровом I2S-усилителе `MAX98357A` и работает в фоновом потоке на Core 0:
* **Тематический текстурный фон:** мягкий процедурный синтез (фильтруемый розовый шум и суб-гармоники) меняется в зависимости от активного режима — шелест воздушных потоков для карты погоды, гул палубы космического корабля для орбитального режима, тихий эфирный шум для авиарадара.
* **Генеративная Lo-Fi мелодия:** медленный алгоритмический секвенсор строит ненавязчивые аккордовые прогрессии в пентатонике.
* **Связь с реальными данными и эволюция:** каждые 5 минут алгоритм плавно меняет базовую тональность и рисунок паттерна, а текущие показания (скорость ветра за окном, уровень геомагнитной активности $K_p$ или пролет МКС) модулируют частоту среза НЧ-фильтра (LPF) и плотность нот.
* **Аппаратный контроль:** громкость регулируется аналоговым потенциометром на передней панели вплоть до полного механического отключения усилителя щелчком в крайнем левом положении.
