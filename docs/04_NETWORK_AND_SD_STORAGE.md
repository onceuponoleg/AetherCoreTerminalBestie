# 04. Сетевая Синхронизация (`script.google.com`) и Структура MicroSD

## 1. Бессерверная синхронизация через Google Apps Script (`script.google.com`)

Чтобы объединить гаджеты, собранные разными людьми в разных странах (включая Россию), без аренды платных VPS-серверов и без проблем с блокировками, используется архитектура **Облачных Папок-Сетей на Google Диске**:

1. **Роль Администратора сети:**
   * Администратор (владелец аккаунта Google) создает на Google Диске папку сети и привязывает к ней скрипт **Google Apps Script** (развертывание в режиме `Web App`, исполнение от имени администратора, доступ: `Anyone with the link`).
   * Скрипт получает уникальный URL вида `https://script.google.com/macros/s/<SCRIPT_ID>/exec` — эта ссылка и является «ключом подключения к сети».
2. **Мультисетевая топология:**
   * В файле `/config.json` на MicroSD-карте каждого гаджета есть массив `"networks": [...]`, куда можно вписать одну или сразу несколько ссылок на разные сети друзей.
   * При синхронизации гаджет отправляет свой дамп телеметрии во все прописанные у него сети и забирает список активных устройств из каждой папки. Итоговый список «Соседей» в меню — это объединение множеств всех узлов из всех подключенных сетей.
3. **Гарантированная работа в РФ и обход блокировок API:**
   * Домен `script.google.com` стабильно работает из РФ по стандартному HTTPS (с поддержкой редиректа `302 Found` в `HTTPClient` на ESP32-S3).
   * Внешние погодные и авиационные API (`api.open-meteo.com`, `api.adsb.lol`, `opensky-network.org`, `seismicportal.eu`) доступны из РФ напрямую.
   * Данные `CelesTrak` (TLE-орбиты спутников) и `NOAA SWPC` (космическая погода), которые иногда закрыты американским Cloudflare для российских IP, **забираются самим облачным скриптом Google (или админским гаджетом вне РФ) один раз в сутки** и складываются готовым файлом `space_cache.json` в папку сети на Google Диске. Все российские гаджеты скачивают свежие орбиты и солнечный ветер напрямую из своей папки сети!



## 2. Оптимизация трафика и формат JSON-пакетов

Чтобы не перегружать квоты Google и канал связи, данные разделены на тяжелую статику (хранится на MicroSD-карте) и сверхлегкую динамику (передается по сети не чаще 1 раза в 5 секунд).

## 3. Структура файлов на MicroSD-карте (Первый запуск и Кэширование)

При сборке устройства пользователь вставляет MicroSD-карту (FAT32) в ПК, записывает на нее конфигурационный файл `/config.json` и сгенерированный файл векторной карты своего региона `/maps/local_100km.vec`. После этого эти базовые данные всегда читаются с флешки мгновенно и не требуют выкачивания из сети при перезагрузках:

```text
SD_CARD_ROOT (FAT32)/
│
├── config.json                     # Главный конфигурационный файл станции (редактируется в Блокноте)
│
├── maps/                           # Векторные карты 100х100 км (берега, реки, дороги, контуры высот)
│   ├── local_100km.vec             # Карта вокруг своей станции (кладется пользователем при первом запуске)
│   ├── neighbor_bestie_02.vec      # Автоматически сохраненный кэш карты соседа №1 (скачивается 1 раз)
│   └── neighbor_bestie_03.vec      # Автоматически сохраненный кэш карты соседа №2
│
└── cache/                          # Оперативный энергонезависимый кэш (переживает перезагрузки по питанию)
    ├── nodes_registry.json         # Список всех известных устройств из подключенных сетей и их координаты
    ├── space_tle_noaa.json         # Суточный кэш орбит спутников TLE и космопогоды NOAA
    ├── weather_forecast.json       # Последний скачанный грид погоды и прогноза +3ч от Open-Meteo
    └── pager_state.json            # Текст последнего «Сообщения дня» и метка времени последней отправки
```

```json
  "device_name": "ALMATY-LAB",

    "password": "MySecretPassword"
  },
  "location": {
    "lat": 43.2380,
    "lon": 76.8890,
    "alt_m": 780,
    "tz_offset_hours": 5
  },
  "settings": {
    "sync_interval_sec": 5,
    "default_neighbor_id": "bestie_node_02",

  },
  "networks": [
    "[https://script.google.com/macros/s/AKfycbx_YOUR_NETWORK_SCRIPT_ID_1/exec](https://script.google.com/macros/s/AKfycbx_YOUR_NETWORK_SCRIPT_ID_1/exec)"
  ]
}
```
