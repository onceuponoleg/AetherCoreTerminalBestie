# 04. Сетевая Синхронизация (`script.google.com`) и Структура MicroSD

## 1. Архитектура синхронизации через `script.google.com`
Для объединения устройств в децентрализованные сети без выделенного VPS-сервера и с гарантированной доступностью из РФ используется связка **Google Drive + Google Apps Script Web App (`script.google.com`)**:
* **Администратор сети** создает папку на своем Google Диске и привязывает к ней скрипт-обработчик (`doPost` / `doGet`), публикуя его как веб-приложение с доступом `Anyone` (доступ по URL-ключу сети).
* **Почему это работает в РФ без VPN:** Домен `script.google.com` не блокируется ТСПУ и принимает стандартные HTTPS-запросы от ESP32-S3 без необходимости проходить сложную OAuth2-авторизацию на самом микроконтроллере.
* **Агрегация сетей:** В конфигурационном файле устройства может быть прописано сразу несколько URL-ключей разных сетей. Список «известных соседей» формируется как объединение всех уникальных узлов из этих папок при загрузке гаджета.
* **Лимиты и тайминги:** Локальные датчики обновляются на экране каждую секунду, а сетевой обмен с базой при просмотре соседнего гаджета ограничен снизу интервалом **5 секунд** (настраивается в меню: `5s / 10s / 30s / 60s`).
* **Проксирование космоданных (CelesTrak и NOAA):** Поскольку американские серверы CelesTrak могут блокировать российские IP через Cloudflare, скрипт администратора (или мастер-устройство за пределами РФ) раз в 24 часа автоматически скачивает свежие TLE-орбиты спутников и сводку геомагнитной активности NOAA, сохраняя их в корне папки сети в файл `space_cache.json`. Все остальные гаджеты забирают эти данные напрямую из папки сети.



## 2. Структура JSON-пакетов обмена

Для минимизации трафика данные разделены на статический паспорт узла (читается один раз при старте) и легкий пакет телеметрии (обновляется каждые 5–60 секунд).

  "name": "ALMATY-CORE",
  "ts": 1730590000,
  "coords": {

## 3. Структура файловой системы на MicroSD-карте (FAT32)

Чтобы устройство мгновенно работало после перезагрузки и не выкачивало тяжелые геоданные по сети, используется MicroSD-карта (слот на экране TFT):

```text
SD_ROOT/
├── config.json                 # Главный конфиг (Wi-Fi, имя станции, свои координаты, ссылки на сети)
├── maps/
│   ├── local_100km.vec         # Бинарный векторный каркас 100х100 км своей локации (дороги, реки, высоты)
│   └── neighbor_<id>.vec       # Кэшированные векторные карты просмотренных соседей
└── cache/
    ├── space_tle.json          # Кэш орбит спутников (валиден 24–72 часа при отсутствии интернета)
    ├── weather_grid.json       # Последний скачанный срез погоды и прогноза +3ч от Open-Meteo
    └── last_chat.json          # Сохраненное «Сообщение дня» для вывода в нижней строке при старте
```

### Пример файла `/config.json` (заполняется пользователем при первом запуске)
```json
{
  "device_id": "station_almaty_01",
  "device_name": "ALMATY-CORE",
  "wifi_ssid": "MyHomeWiFi",
  "wifi_pass": "SecretPassword123",
  "home_coords": {
    "lat": 43.2380,
    "lon": 76.8890,
    "alt_m": 780
  },
  "sync_interval_sec": 5,
  "filament_brightness_pct": 60,
  "networks": [
    "https://script.google.com/macros/s/AKfycbx_NETWORK_1_ID/exec",
    "https://script.google.com/macros/s/AKfycbx_NETWORK_2_ID/exec"
  ]
}
```
